# NFOT v7 preregistration draft

**Registration status:** Not registered. This document is a draft for qualified supervisory and ethics review.

- **Primary hypothesis:** randomized post-selection feedback delay changes the prespecified subsequent outcome.
- **Null:** no assigned-condition contrast in that outcome.
- **Primary estimand:** intention-to-treat mean or probability contrast between assigned timing conditions, with participant clustering represented.
- **Conditions:** exact delay values and tolerance are unresolved pending engineering timing validation.
- **Randomization:** participant-balanced trial/block assignment; exact unit and seed to be frozen before data collection.
- **Events:** `t0`, feedback endpoint, assigned delay, achieved command timing, and physical display onset criterion must be defined before enrollment.
- **Outcome:** one prespecified downstream performance/learning outcome; same-trial correctness is secondary.
- **Model:** participant-clustered or mixed-effects binary-outcome model, formula frozen before unblinding.
- **Exclusions:** only technical, eligibility, invalid-sequence, withdrawal, and prespecified timing failures; no outcome-dependent exclusions.
- **Missingness:** report by assigned condition and participant; primary handling frozen before analysis.
- **Multiplicity:** one primary contrast; all other outcomes and features labeled secondary/exploratory.
- **Robustness:** timing tolerance, order, session, influential participant, and model-form checks.
- **Stopping:** no interim inferential stopping unless specified before enrollment.
- **Falsification:** null/opposite downstream effect, failed timing delivery, or explanation by ordinary task/order effects.
- **Deviations:** logged with timestamp, reason, affected records, and consequence; no silent protocol repair.

Unresolved decisions requiring a qualified supervisor: exact delay levels, primary downstream outcome, sample size, randomization unit, physical timing instrumentation, ethics pathway, and data-retention/privacy plan.
