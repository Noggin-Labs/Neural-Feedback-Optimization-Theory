# NFOT v7 applications and translation

## Closed-loop BCI

The most credible near-term application is interface timing monitoring. A validated gap pipeline could identify system-level timing changes, compare assigned and achieved feedback, support quality control, and generate hypotheses for adaptive policies. This is distinct from improving BCI accuracy. Accuracy improvement requires a fair baseline comparison, held-out validation, timing reliability, and prospective testing.

A minimum BCI validation study would use verified event semantics, external timing checks where physical onset matters, repeated sessions, participant-aware analysis, and a prespecified operational outcome. It should retain technical failures rather than hide them through outcome-dependent exclusions.

## Neuroadaptive educational technology

A measured feedback interval might eventually inform adaptive pacing or feedback scheduling, but BCI results cannot be assumed to generalize to classrooms. The minimum study would define a learner-facing outcome such as delayed retention, compare against ordinary instructional timing, monitor burden and accessibility, and use appropriate supervision, privacy, and consent/assent for any children or education records.

No evidence in this repository supports claims for ADHD, autism, dyslexia, or other clinical/neurodevelopmental populations. Potential harms include unnecessary surveillance, misclassification of engagement, inequitable adaptation, and overinterpretation of noisy timing measures. Data minimization and independent evaluation are required.
