# NFOT v7 novelty and positioning

| Question | Existing framework | NFOT distinction | Evidence for distinction | What would establish added value |
|---|---|---|---|---|
| What is timed? | Interface latency, reaction time, feedback delay, event-to-event latency | A prespecified event-to-feedback interval with distributional summaries | The repository defines `L`; source semantics remain blocked | Independent source reconstruction and measurement-error characterization |
| Does timing associate with performance? | Latency-performance and speed-accuracy analyses | Within/between decomposition of a closed-loop gap | Historical association is reported, not reproduced | Verified labels, prespecified clustered model, sensitivity survival |
| Does history matter? | Temporal credit assignment and sequential learning models | Prior-gap distribution/history as a candidate feature | Hypothesis only | Fair held-out improvement over conventional latency/history baselines |
| Does timing cause learning? | Randomized delayed-feedback learning studies | Randomized post-selection delay with downstream outcome | Protocol proposed only | Valid randomized contrast with reliable timing delivery |
| Is there a biological mechanism? | Eligibility traces and three-factor learning | Possible interpretation of the measured gap | Analogy/motivation only | Concurrent physiological measures and mechanistic experiment |

The most defensible current positioning is a measurement-and-validation framework for separating nominal, recorded, achieved, and physical feedback timing and testing whether timing distributions add value beyond conventional latency. NFOT does not currently demonstrate a new law or mechanism. If grouped benchmarks show no reliable added value over a conventional latency baseline, the theory should be narrowed to instrumentation and experimental design.
