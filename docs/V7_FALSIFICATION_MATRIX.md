# NFOT v7 falsification matrix

| Hypothesis | Supports | Weakens/contradicts | Competing explanation | Discriminating test |
|---|---|---|---|---|
| Gap is reconstructible | Independent source analysts recover same rows and endpoints | Missing/ambiguous events or materially different rows | Conversion/clock artifact | Raw/source-stream crosswalk |
| Gap associates with accuracy | Verified within-person estimate survives sensitivity | Association disappears after labels/order/difficulty checks | Difficulty, fatigue, participant state | Prespecified clustered model |
| Gap distribution adds value | Fair grouped benchmark improves calibrated held-out metrics | Mean/conventional latency matches or wins | Leakage or overfit summaries | Nested participant-grouped benchmark |
| Delay affects subsequent behavior | Randomized downstream contrast with valid timing | Null/opposite result | Order, expectancy, technical failure | Balanced randomized experiment |
| NFOT adds beyond ordinary latency | Distinct prediction survives baseline comparison | Simpler latency model performs equally | Existing latency framework | Locked baseline versus NFOT feature model |
| Gap reflects a biological mechanism | Convergent timing plus neural/physiological evidence | Behavioral gap uncoupled from neural measure | System/interface timing | Concurrent EEG/physiology and causal manipulation |

An unfavorable result must narrow or reject the affected hypothesis rather than trigger post hoc redefinition.
